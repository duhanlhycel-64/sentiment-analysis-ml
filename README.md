# Course Review Sentiment Analysis (Machine Learning)

A machine learning project built for analyzing and classifying course review sentiments using Natural Language Processing (NLP) techniques and Python.

## Project Overview
This project processes student/user course reviews from a dataset (`reviews.csv`), performs data preprocessing and exploratory data analysis (EDA), and applies machine learning workflows to evaluate and predict sentiment polarity (positive, neutral, or negative).

## Tech Stack & Libraries
* **Language:** Python
* **Environment:** Google Colab / Jupyter Notebook
* **Libraries:** Pandas, Scikit-Learn, NumPy, Matplotlib/Seaborn (for data manipulation and modeling)
